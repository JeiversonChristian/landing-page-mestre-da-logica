# Landing Page: Mestre da Lógica 🧠

> **Status:** Em Desenvolvimento 🚧

## 📖 Sobre o Projeto
Este é um projeto de estudo e portfólio focado na criação de uma **Landing Page de Alta Conversão**. 

O objetivo é simular um cenário real de venda de um produto digital (um curso online de Lógica e Pensamento Crítico), aplicando técnicas de **Copywriting**, **Design Persuasivo** e **Otimização de Performance**.

Este projeto serve como modelo base para serviços de criação de páginas de vendas (Sales Pages) para infoprodutores e prestadores de serviço.

## ✨ Funcionalidades Planejadas
* **Hero Section Impactante:** Manchete, subtítulo e CTA (Call to Action) otimizados.
* **Seção de "Dor e Solução":** Estrutura narrativa para conexão com o cliente.
* **Accordion (FAQ):** Perguntas frequentes com lógica de abrir/fechar em JavaScript.
* **Contador Regressivo (Countdown):** Gatilho mental de urgência ("Oferta encerra em...").
* **Botão Sticky:** Botão de compra que acompanha a rolagem da página.
* **Animações de Scroll:** Elementos surgindo suavemente (Fade In) para engajamento visual.
* **Design Responsivo:** Otimização total para Mobile First.

## 🚀 Tecnologias
* **HTML5:** Semântica e SEO.
* **CSS3:** Arquitetura Modular (CSS Modules), Flexbox, Grid e Variáveis (`:root`).
* **JavaScript (ES6):** Manipulação de DOM para interatividade (FAQ, Timer, Scroll).

## 📂 Estrutura do Projeto
O projeto segue uma arquitetura modular para facilitar a manutenção e escalabilidade:

```text
/
├── css/
│   ├── global.css        # Variáveis e resets
│   └── modulos/          # Estilos separados (hero.css, faq.css, footer.css, etc.)
├── js/
│   ├── app.js            # Arquivo principal
│   └── modulos/          # Lógica separada (accordion.js, timer.js, etc.)
├── imagens/              # Ativos visuais
└── index.html            # Estrutura principal
```
